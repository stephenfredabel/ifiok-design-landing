# Ifiok Design Landing Page

A premium landing page for the Ifiok Design product, built to match the Ifiok print brand language with a modern SaaS feel.

## Brand

- Primary Teal: `#008080`
- Accent Gold: `#EAB308`
- Background: `#F8FAFC`
- Dark: `#0F172A`

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
